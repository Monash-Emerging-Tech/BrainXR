# AimlabsXRModals

Purpose-built native stereoscopic 3D spatial modals for the Aimlabs Cognitive Test in WebXR.

### Purpose
Provides dedicated 3D spatial user interfaces for test briefing (dual ergonomically angled round cards), 3D depth-pulsing countdown digits, intermission telemetry review with rule reversal alerts, and comparative cognitive performance reports. Integrates authentic OffBit typography, miniature glowing/tumbling physical target tokens, and tactile 3D interactive action buttons with controller haptics.

### Sub-components
- `XRReadyModal`: Angled dual-card briefing with 3D rule tokens and start/exit buttons.
- `XRCountdownModal`: Depth-pulsing 3-2-1 digits with fixation guidance.
- `XRIntermissionModal`: Round 1 metric badges and rule reversal alert.
- `XRFinishedModal`: Side-by-side comparative metric pillars and score readouts.
- `XRActionButton`: Tactile volumetric 3D pill button with depth translation, perimeter glow, and haptic pulses.
- `XRRuleToken`: Physical 3D cyan sphere or ruby box with rotation physics and rule actions.
