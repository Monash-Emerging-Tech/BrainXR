# MeditatingFigure

A clean, minimalist vector SVG graphic of a person seated in a meditative lotus posture.

## Inputs & Props
- `className?: string`: Optional CSS classes for container layout and sizing.
- `glowPrefrontal?: boolean`: When true, enlarges and highlights the forehead/prefrontal cortex node with active pulsation.

## Behavior
Renders responsive SVG lines with an indigo/cyan gradient and ambient aura. A pulsing node sits on the forehead to visually introduce the prefrontal cortex concept before transitioning to the 3D Digital Twin headset.
