# AccessibilityMenu

A small dropdown button for picking a color-vision filter mode, backed by [[../../hooks/useVisionMode|useVisionMode]].

**Props**: `align?` ("left" | "right"), `direction?` ("up" | "down", which way the dropdown opens), `className?`, `buttonClassName?` (overrides the default trigger-button styling entirely when set).

Closes on outside click/tap, Escape, or selecting a mode.
