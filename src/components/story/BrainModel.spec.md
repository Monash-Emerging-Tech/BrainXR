# BrainModel

The segmented 3D brain shared by [[../HeadWrapper/index|HeadWrapper]] (the default headset view), [[../story-v2/BrainStageV2|BrainStageV2]] (the v2 onboarding story), and [[../onboarding/OnboardingBrainStage/index|OnboardingBrainStage]]: loads the Sketchfab GLB, centers/normalizes it, gives each lobe in `BRAIN_REGIONS` its own tintable material, and rotates/glows the active region.

**Props**: `activeIndex` (index into `BRAIN_REGIONS`, or -1), `prefrontal?`/`prefrontalRef?`, `pulse?`, `reducedMotion?`, `prefrontalColor?`, `customYaw?`/`customYawRef?` (ref wins, for 60/120fps sync with a parent scroll rig), `showVRHeadset?` + `vrHeadsetMount?`/`vrHeadsetMountRef?`, `children?` (mounted inside the rotating rotor group, for exact mechanical lockstep with the brain's own turn), `stageOpacityRef?`, `depthWrite?`/`depthWriteRef?`.

**Non-obvious**: the model's forward axis and each region's facing yaw are *derived* at runtime from the frontal/occipital lobe centroids rather than hardcoded, specifically so re-exporting the source GLB can't silently break the tour. Each lobe gets its own cloned `MeshStandardMaterial` (via `onBeforeCompile` shader injection for the fresnel rim / prefrontal glow / CENTRAL band) because the source file's meshes share only 3 materials, and tinting a shared one would light every lobe in that group at once. Any mesh not belonging to a named `BRAIN_REGIONS` node (brainstem, deep structures, corpus callosum, stray annotation pins under `CFG.minMeshVerts`) is force-ghosted onto a shared `restMaterial` so the brain still reads as anatomically whole.
